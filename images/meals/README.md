# CookLikeMe Meal Images

Meal photography lives in this folder.

The app automatically converts each recipe title to a lowercase hyphenated filename and looks for a `.webp` image here.

Examples:

- `Garlic Butter Steak over Rice` → `garlic-butter-steak-over-rice.webp`
- `Honey Garlic Wings with Yellow Rice & Cabbage` → `honey-garlic-wings-with-yellow-rice-and-cabbage.webp`
- `Caribbean Curry Chicken with Rice` → `caribbean-curry-chicken-with-rice.webp`
- `Cajun Shrimp Alfredo` → `cajun-shrimp-alfredo.webp`

Until a photo is uploaded, CookLikeMe displays a branded food-category fallback instead of a broken image.
